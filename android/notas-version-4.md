# Notas de la versión · Android versionCode 4 · 1.3.0 · 08/10/2026

Archivo: `fairscan-v4-958f835.aab` (firmado con la clave de subida). Para Play Console → Pruebas → Prueba cerrada → Crear versión nueva. Segunda de las tres versiones de A9. Responde a la única observación del informe de Testers Community (07/10): el botón "atrás" cerraba la app de golpe.

## es-419 (Español, Latinoamérica)

El botón "atrás" del teléfono ahora se comporta como se espera: cierra la hoja abierta, vuelve a la pantalla anterior y, en la pantalla principal, pide un segundo toque antes de salir. Nueva página web de FairScan con la explicación del producto y soporte renovado. Pequeños ajustes de estabilidad.

## en-US (English)

The phone's back button now behaves as expected: it closes the open sheet, returns to the previous screen and, on the main screen, asks for a second tap before exiting. New FairScan website with product information and refreshed support page. Minor stability improvements.
